# Plan: EasyPlan V1 (Phasen 1–3 aus Konzept.md)

Erstellt: 2026-10-30 · Status: Phasen 1–3 done (alle drei per PR in `master` gemergt, letzter: PR #7, Merge-Commit `8913376`); offen: T22 (Release `v1.0.0`) und T23 (Dependabot-Nachbesserung). Phase 4 siehe `.kilo/plans/2026-11-01-phase-4-uebergabe.md`.

## Ziel
Self-hosted Mini-App in Go, die Fixkosten pro Konto zusammenrechnet (Monat/Woche/Tag), die Reserve für die nächsten N Tage ausweist und kommende Zahlungen zeigt. Ein Binary, eine SQLite-Datei. Massgebend ist `Konzept.md`. Phase 4 (Optional, §11) ist nicht Teil dieses Plans.

## Arbeitsweise

- Pro Phase: coder → tester → reviewer → documenter. Commit, Push und PR nur durch den planner nach Bestätigung des Menschen.
- Schleifenbremse: höchstens 3 Runden coder↔reviewer bzw. tester↔debugger pro Task.

## Ergänzungen zum Konzept (Vorschläge, zu bestätigen)
1. **Zeitzonen:** `distroless/static` enthält keine tzdata → `import _ "time/tzdata"` in `main.go`, sonst scheitert `TZ=Europe/Zurich`.
2. **Backup bei `read_only: true`:** `VACUUM INTO` darf nicht nach `/tmp` schreiben (read-only) → temporäre Datei in `/data` anlegen und nach dem Download löschen.
3. **Healthcheck:** distroless hat keine Shell → `HEALTHCHECK CMD ["/easyplan","healthcheck"]` in Exec-Form.
4. **Volume-Rechte:** `./data` muss dem Nutzer `nonroot` (UID 65532) gehören → in README vermerken.
5. **Dev-Standard:** `EASYPLAN_DATA` ist standardmässig `/data`; für `go run` in der README `EASYPLAN_DATA=./data` setzen (oder Default `./data` ausserhalb Docker).
6. **„Nächste Zahlung“:** `Occurrences(from, to)` genügt nicht für lange Intervalle (z. B. alle 3 Jahre) → zusätzliche reine Funktion `Next(entry, after)` auf demselben Kern.
7. **Validierung:** `ends_on >= start_date`; bei `once` werden `interval` und `ends_on` ignoriert/auf Standard gesetzt.
8. **Origin-Prüfung:** Schreibende Requests ohne `Origin`-Header explizit definieren (Vorschlag: ablehnen) und Verhalten hinter Reverse Proxy (`Host` bleibt erhalten, Caddy-Standard) dokumentieren.
9. **Rundung:** Anzeige auf ganze Franken, kaufmännisch (half away from zero); Tausendertrenn mit `'`.
