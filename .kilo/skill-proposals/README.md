# Skill-Vorschläge

Ablage für Vorschläge an den `skiller`, die aus der täglichen Arbeit entstanden sind.

Format je Vorschlag (Dateiname `JJJJ-MM-TT-kurztitel.md`):

```markdown
# <Titel>

## Beobachtung
<Was ist in der Praxis aufgetreten>

## Vorschlag
<Was soll in welchem Skill oder Agenten geändert werden>

## Begründung
<Warum das wiederkehrend nützlich ist>
```

Regeln:

- Nur Vorschläge, keine direkten Änderungen an Skills oder Agenten.
- Der `skiller` entscheidet über die Umsetzung und erstellt dafür Branch und Pull Request im `kilo`-Repo.
